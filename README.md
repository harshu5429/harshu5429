### 🗺️ GaavConnect
**AI-Powered Rural Route Optimization**

> Production-grade multi-modal transport routing platform solving the **Traveling Salesman Problem** with a custom **Genetic Algorithm** (tournament selection, order crossover, elite preservation). Offline-first PWA with crowd-sourced traffic reporting.

**Key Features:**
- 🧬 Custom Genetic Algorithm TSP Solver
- 🚌 Bus, Auto, Bike & Walking routing
- 📡 Offline-first with Service Workers + IndexedDB
- 👥 Crowd-sourced reports with upvote/downvote
- 💰 Dynamic fare calculation & reliability metrics

```
User Input → Genetic Algorithm → Optimal Route
          → Google Maps API → Multi-Modal Output
          → PWA Cache → Offline Sync
```

### 💰 SaveUp (sumup)
**Gamified Micro-Savings Fintech Platform**

> A fintech platform that automatically **rounds up everyday transactions** to nearest ₹5 and invests the difference. Features real QR/UPI integration, achievement badges, social leaderboards, and offline resilience.

**Key Features:**
- 🎯 Automated round-up investments
- 📷 Live QR camera scanning (Html5Qrcode)
- 🏆 Gamification: badges & leaderboards
- 📊 Financial analytics with animations
- 🔌 Offline fallback via localStorage sync

```
Transaction → Round-up Engine → Savings Goal
           → Neon PostgreSQL → Leaderboard
           → QR/UPI → Badge Awards
```
